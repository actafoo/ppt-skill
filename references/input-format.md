# 한 번에 받는 입력 형식

사진 여러 장과 PPT/원고를 한 번에 첨부할 수 있다. 아래 형식은 안내용이며 사용자가 이 형식을 반드시 채울 필요는 없다. 실제 첨부 파일명으로 연결한다.

```text
교사 웹 발표자료 제작 스킬로 아래 내용과 첨부 사진을 웹 발표자료로 만들어줘.

[전체 조건]
- 발표 주제:
- 청중:
- 발표 시간:
- 페이지 수: 자동 구성 또는 지정
- 디자인과 조작: 스킬 기본 설정

[1페이지]
- 사진 파일: 01.jpg
- 제목:
- 전달할 내용:
- 그대로 쓸 화면 문구: (선택)
- 발표자 메모: (선택)

[2페이지]
- 사진 파일: 02.jpg, 03.jpg
- 제목:
- 전달할 내용:
- 발표자 메모: (선택)

[요청]
- 내용에 맞춰 짧은 화면 문구와 배치를 구성해줘.
- 모든 페이지에 사진 사용 / 필요한 페이지만 사용.
```

PPTX가 있으면 ‘첨부 PPT의 내용과 순서를 참고하고 사진은 원본 첨부를 사용해줘’ 한 문장으로도 시작한다. 전체 원고만 있으면 장별로 나눈다. 사진 번호만 있고 파일명이 다르면 첨부 목록에서 대응이 확실한 것만 연결하고 모호한 연결만 질문한다. 입력을 코드나 JSON으로 작성하도록 사용자에게 요구하지 않는다.
